## 第1問（共通問題）

- <a name="q1-1"></a>**（1） 知的財産権の分類**（正答 **ウ**）
  意匠権は製品外観や一定の画面画像のデザインを保護する産業財産権。発明を守る特許や標識を守る商標と区別する。 [原本 p.4](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=4)
- <a name="q1-2"></a>**（2） 著作隣接権**（正答 **ア**）
  著作隣接権は作品を公衆に伝える実演家やレコード製作者などの権利。元の作品を作った著作者の権利とは別に扱う。 [原本 p.4](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=4)
- <a name="q1-3"></a>**（3） 著作権の扱い**（正答 **ウ**）
  創作した著作者には、経済的利益を守る著作財産権と、人格的利益を守る著作者人格権が生じる。 [原本 p.5](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=5)
- <a name="q1-4"></a>**（4） 許諾なしで利用できる場合**（正答 **ア**）
  ©表示の有無だけで、写真を無断転載してよいかは決まらない。保護期間、利用許諾、引用などの条件を確認する。 [原本 p.5](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=5)

## 第2問

- <a name="q2-a"></a>**a 処理後の画像の識別**（正答 **イ**）
  彩度を下げると、形や明暗はおおむね保たれ、色の鮮やかさが落ちる。輪郭の位置と色味を別々に比較する。 [図表・原本 p.8](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=8)
- <a name="q2-b"></a>**b トーンカーブの識別**（正答 **ウ**）
  トーンカーブは横軸が元の明るさ、縦軸が変換後の明るさ。曲線が対角線の上なら明るく、下なら暗くなる。 [図表・原本 p.9](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=9)
- <a name="q2-c"></a>**c 彩度対比**（正答 **イ**）
  同じ色でも、彩度の低い背景の近くではより鮮やかに見える場合がある。変化する印象が鮮やかさなら彩度対比。 [図表・原本 p.10](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=10)
- <a name="q2-d"></a>**d 画像処理の手法**（正答 **エ**）
  クロマキーは一定の色の領域を識別して別画像に差し替える。グリーンバック合成が代表例。 [原本 p.10](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=10)
- <a name="q2-e"></a>**e ソリッドモデルのスイープ**（正答 **ウ**）
  スイープは断面を移動または回転させた軌跡で立体を表す。円錐なら直角三角形を一辺の周りに回転させると理解しやすい。 [図表・原本 p.11](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=11)

## 第3問

- <a name="q3-a"></a>**a 音の波形と知覚**（正答 **カ**）
  波形の周期が同じなら音の高さも同じ。周期内の形が違えば、周波数成分が異なって音色が変わり得る。 [図表・原本 p.12](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=12)
- <a name="q3-b"></a>**b 網膜と視細胞**（正答 **イ**）
  桿体は暗い所の視覚を担う。錐体は波長への感度が異なる3種類があり、色の識別に関わる。 [原本 p.13](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=13)
- <a name="q3-c"></a>**c メタバース**（正答 **イ**）
  メタバースは参加者がアバターなどで入り、他の人と交流できるネット上の仮想空間。ARは実環境への情報の重畳。 [原本 p.13](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=13)
- <a name="q3-d"></a>**d ピクトグラム**（正答 **エ**）
  非常口の人型と矢印のように、意味を絵記号で伝えるものがピクトグラム。 [原本 p.13](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=13)

## 第4問

- <a name="q4-a"></a>**a タイポグラフィ**（正答 **エ**）
  プロポーショナルフォントでは字形に応じて文字幅が異なる。等幅書体では各文字が同じ幅を占める。 [原本 p.14](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=14)
- <a name="q4-b"></a>**b 音声データの圧縮**（正答 **イ**）
  48,000×8×2＝768 kbit/s。64 kbit/sで送るには元の12分の1まで圧縮する。 [原本 p.14](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=14)
- <a name="q4-c"></a>**c 録音編集による音声合成**（正答 **イ**）
  録音編集方式は収録済みの文や文節を組み合わせて再生する。駅や車内など、内容が限定される案内に使える。 [原本 p.15](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=15)
- <a name="q4-d"></a>**d 機器間の色の変換**（正答 **エ**）
  出力機器で再現できない色も色管理の対象。出力側の色域へ圧縮・近似して表現する方法がある。 [原本 p.15](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=15)

## 第5問

- <a name="q5-a"></a>**a 記憶装置**（正答 **ア**）
  RAMにはDRAMやSRAMがある。記憶装置を比べるときは揮発性・容量・読み書きの速さを分けて考える。 [原本 p.16](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=16)
- <a name="q5-b"></a>**b OSの機能**（正答 **ア**）
  プロセスやメモリなどの基本資源を管理する中核はカーネル。ライブラリは機能を他のプログラムから再利用するための部品。 [原本 p.16](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=16)
- <a name="q5-c"></a>**c サーバ仮想化**（正答 **ウ**）
  ホスト型仮想化はホストOSの上で仮想化ソフトを動かし、その上でゲストOSを稼働させる。 [原本 p.17](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=17)
- <a name="q5-d"></a>**d コンテナ**（正答 **エ**）
  コンテナイメージは実行環境を再利用できるパッケージ。コンテナは通常、OSのカーネルをホストと共有して隔離する。 [原本 p.17](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=17)

## 第6問

- <a name="q6-a"></a>**a ネット上の資源を指す記法**（正答 **オ**）
  URLはネット上の資源を指定する文字列。Webの場合はスキーム、ホスト、パスなどで構成される。 [原本 p.18](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=18)
- <a name="q6-b"></a>**b サブネットマスク**（正答 **オ**）
  255.255.128.0は/17。10.16.192.32のネットワークは10.16.128.0/17で、第3オクテットが128〜255の10.16で始まる候補が該当する。 [図表・原本 p.18](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=18)
- <a name="q6-c"></a>**c サービスプロバイダ**（正答 **イ**）
  データセンターは機器を置く場所、電力、回線、物理セキュリティなどを提供する。ISPはインターネット接続を提供する。 [原本 p.19](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=19)
- <a name="q6-d"></a>**d モバイル回線**（正答 **イ**）
  対応PCもSIM等によってモバイル回線を利用できる。端末は無線で基地局につながり、その先は事業者の網を通る。 [原本 p.19](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=19)

## 第7問

- <a name="q7-a"></a>**a マルウェア**（正答 **イ**）
  画面や手元を見て入力を盗むのはショルダーハッキング。コンピュータ上で動く悪意あるソフトとは分類が違う。 [原本 p.20](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=20)
- <a name="q7-b"></a>**b VPN**（正答 **イ**）
  VPNは物理回線の上に仮想的な専用経路を作る。インターネットVPNでは公開インターネットを下の回線に使う。 [原本 p.20](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=20)
- <a name="q7-c"></a>**c ユーザー認証**（正答 **エ**）
  ワンタイムパスワードは一度認証に使うと再利用できない。方式によって使わなくても短時間で期限切れになる。 [原本 p.21](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=21)
- <a name="q7-d"></a>**d 機密性・完全性・可用性**（正答 **ウ**）
  機密性は権限のない者に読ませないこと。完全性は正しさを保つこと。可用性は必要時に使えること。 [原本 p.21](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=21)

## 第8問

- <a name="q8-a"></a>**a システムの企画と要件**（正答 **オ**）
  企画段階では誰のために何を実現するかを決める。対応ブラウザや版の指定は実装・動作環境の要件。 [原本 p.22](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=22)
- <a name="q8-b"></a>**b オブジェクト指向**（正答 **ア**）
  カプセル化では内部データや処理への外部アクセスを制限し、公開した操作を通じて利用させる。 [原本 p.22](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=22)
- <a name="q8-c"></a>**c アプリのテスト**（正答 **ウ**）
  単体は個々の部品、結合は部品間の連携、負荷は想定ユーザー数や処理量に耐えるかを確認する。 [原本 p.23](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=23)
- <a name="q8-d"></a>**d アプリの運用**（正答 **エ**）
  アクティブ／アクティブでは複数系統が普段から稼働し、アクティブ／スタンバイでは障害時に待機系へ切り替える。 [原本 p.23](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=23)

## 第9問

- <a name="q9-a"></a>**a Webブラウザ**（正答 **ウ**）
  ブラウザとWebサーバの通信はHTTP(S)。DHCPは機器にネットワーク設定を配布するための規約。 [原本 p.24](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=24)
- <a name="q9-b"></a>**b シェアリングエコノミー**（正答 **ア**）
  空き部屋の貸し出しや個人間取引の仲介では、ネットのプラットフォーム上で供給者と利用者をつなぐ。 [原本 p.24](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=24)
- <a name="q9-c"></a>**c オウンドメディア**（正答 **エ**）
  自社で保有・管理する媒体がオウンドメディア。利用者の投稿が主体のメディアはCGMとして区別できる。 [原本 p.25](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=25)
- <a name="q9-d"></a>**d ネット広告**（正答 **ウ**）
  Webページの広告枠に画像や動画を表示するのがディスプレイ広告。検索語に連動する広告とは掲載方法が違う。 [原本 p.25](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=25)

## 第10問

- <a name="q10-a"></a>**a 暗号資産**（正答 **ウ**）
  ビットコインのような暗号資産は取引記録をブロックチェーンで管理する。価格が法定通貨に対して固定されているとは限らない。 [原本 p.26](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=26)
- <a name="q10-b"></a>**b 携帯電話の通信技術**（正答 **ウ**）
  個人所有の端末を仕事に使うのはBYOD。端末を組織として設定・制御する仕組みがMDM。 [原本 p.26](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=26)
- <a name="q10-c"></a>**c デスクトップ仮想化**（正答 **ウ**）
  VDIはユーザーのデスクトップ環境をサーバ側で動かす。ゼロクライアントも画面転送を扱う最小限の回路を持ち、汎用PCとしての処理はサーバに任せる。 [原本 p.27](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=27)
- <a name="q10-d"></a>**d デジタルアーカイブ**（正答 **ウ**）
  デジタルアーカイブは資料をデジタル化・保存し、参照できるようにする。デジタルデバイドはアクセスや利用能力の格差。 [原本 p.27](https://www.cgarts.or.jp/v1/kentei/past/img/2024_07/t/e/exp_mm_24a.pdf#page=27)
