## 第1問（共通問題）

- <a name="q1-1"></a>**（1） 著作者人格権**（正答 **イ**）
  人格権には公表権、氏名表示権、同一性保持権がある。著作者本人に帰属し、譲渡できない。 [原本 p.4](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=4)
- <a name="q1-2"></a>**（2） 著作隣接権**（正答 **エ**）
  レコード製作者には録音物の複製に関する権利がある。他の製作者に限らず無断複製が権利に触れ得る。 [原本 p.4](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=4)
- <a name="q1-3"></a>**（3） 著作物の成立**（正答 **エ**）
  アイデアと創作的な表現を区別する。次の作品に使う候補者の名前を口頭で伝えただけでは、作品の表現には当たらない。 [原本 p.4](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=4)
- <a name="q1-4"></a>**（4） 著作権侵害**（正答 **エ**）
  撮影に付随して入った演奏音が軽微なら、ただちに侵害とはいえない。使い方、分量、元作品の扱いなどで例外の該当性を考える。 [原本 p.5](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=5)

## 第2問

- <a name="q2-a"></a>**a トーンカーブと画像コントラスト**（正答 **ウ**）
  S字のトーンカーブは暗部をより暗く、明部をより明るくでき、コントラストを増す。ヒストグラムの広がりも判断材料。 [図表・原本 p.8](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=8)
- <a name="q2-b"></a>**b 色の対比と同化**（正答 **エ**）
  近くに置いた色に寄って見えるのが同化。緑の網で野菜の緑が強まって見える例で区別する。 [原本 p.9](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=9)
- <a name="q2-c"></a>**c カラーモデル**（正答 **ア**）
  CIE RGBの等色では、実在する三原色の混合だけで表せない色に負の刺激値を使う場合がある。 [原本 p.9](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=9)
- <a name="q2-d"></a>**d カラーマネジメント**（正答 **イ**）
  機器ごとの色空間をICCプロファイルなどで記述し、機器に依存しない共通色空間を介して変換する。 [原本 p.9](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=9)
- <a name="q2-e"></a>**e 反転・縮小・回転の合成**（正答 **エ**）
  順番に座標へ適用する。y軸で鏡映、x方向を半分、時計回り90度なら、点 (x, y) は (y, x/2) に移る。 [図表・原本 p.10](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=10)

<a name="q3"></a>

## 第3問

- <a name="q3-a"></a>**a 奥行きの手がかり**（正答 **ウ**）
  奥へ行くほど模様が細かく詰まって見えるのがテクスチャの勾配。光の当たり方による明暗の差で凹凸を判断するのが陰影。どちらも片目で使える手がかり。 [図表・原本 p.11](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=11)
- <a name="q3-b"></a>**b 音の周期と知覚**（正答 **エ**）
  大きな音が目立ちやすい一方、注意を向けると混雑の中で特定の話し声も聞き分けられる。 [原本 p.11](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=11)
- <a name="q3-c"></a>**c 感覚間相互作用**（正答 **イ**）
  あいまいな感覚情報が別の感覚の影響を受ける。例えば同じ音でも、視覚情報によって違う音として聞こえることがある。 [原本 p.12](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=12)
- <a name="q3-d"></a>**d 人とコンピュータの対話**（正答 **イ**）
  ユーザーの操作に機器が返す結果はフィードバック。視覚や音による反応で、操作が伝わったかを判断できる。 [原本 p.12](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=12)

<a name="q4"></a>

## 第4問

- <a name="q4-a"></a>**a PCMの標本化とデータ量**（正答 **カ**）
  20 kHzまで再現するには40 kHz以上を目安に標本化する。40,000標本/秒×16ビット×10秒÷8＝800,000バイト。モノラルなので1チャンネル。 [原本 p.13](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=13)
- <a name="q4-b"></a>**b 文字コード**（正答 **ア**）
  Unicodeは文字の番号体系。UTF-8はASCIIと互換の範囲を持つ可変長の符号化方式。 [原本 p.13](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=13)
- <a name="q4-c"></a>**c デジタル文書の構造**（正答 **イ**）
  XMLはタグで階層構造を記述し、用途に合わせて要素名や構造を定義できる。 [原本 p.14](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=14)
- <a name="q4-d"></a>**d 音声・音響の処理**（正答 **ア**）
  録音編集方式は収録済みの音を組み合わせ、規則合成は読み方や韻律を生成する。任意文のTTSを録音編集方式だけの代表例と見なすのは不正確。 [原本 p.14](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=14)

## 第5問

- <a name="q5-a"></a>**a コンピュータのハードウェア**（正答 **イ**）
  DRAMは電源が切れると保持内容が消える揮発性メモリ。通電中も定期的なリフレッシュが必要。 [原本 p.15](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=15)
- <a name="q5-b"></a>**b メモリと記憶装置**（正答 **イ**）
  ROM系は電源を切っても内容が残る。起動に必要なファームウェアなどの格納に向く。 [原本 p.15](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=15)
- <a name="q5-c"></a>**c OSの機能**（正答 **イ**）
  デバイスドライバはOSから周辺機器を制御するためのソフトウェア。 [原本 p.15](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=15)
- <a name="q5-d"></a>**d サーバ仮想化**（正答 **ウ**）
  CPUやメモリに余裕があれば、1台の物理サーバ上に複数のVMを稼働させられる。 [原本 p.16](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=16)

## 第6問

- <a name="q6-a"></a>**a 通信プロトコル**（正答 **イ**）
  プロトコルは通信相手どうしが使う手順・形式・規約。階層ごとに異なる役割を持つ。 [原本 p.17](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=17)
- <a name="q6-b"></a>**b ルーティング**（正答 **エ**）
  IPルータは宛先アドレスを見て、経路表から次に送る先を選ぶ。 [原本 p.17](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=17)
- <a name="q6-c"></a>**c IPアドレス**（正答 **ア**）
  プライベートアドレスは内部ネットワークで使用し、公衆インターネット上では通常ルーティングされない。 [原本 p.17](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=17)
- <a name="q6-d"></a>**d 機器のインターネット接続**（正答 **オ**）
  携帯回線はSIM等で加入者を識別し、基地局を通る。無線LANはアクセスポイントを経由し、その先の回線は別に考える。 [図表・原本 p.18](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=18)

## 第7問

- <a name="q7-a"></a>**a データ通信の暗号化方式**（正答 **ウ**）
  公開鍵で暗号化したデータは対応する秘密鍵で復号する。署名では秘密鍵と公開鍵の役割が暗号化時とは異なる。 [原本 p.19](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=19)
- <a name="q7-b"></a>**b ファイアウォール**（正答 **イ**）
  IPやポート番号で通過可否を決めるのはパケットフィルタリング。コンテンツフィルタリングは中身や対象URLなどで判断する。 [原本 p.19](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=19)
- <a name="q7-c"></a>**c VPN**（正答 **イ**）
  IP-VPNは通信事業者の閉域IP網を使う。インターネットVPNは公衆回線を使う。 [原本 p.20](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=20)
- <a name="q7-d"></a>**d TLSの手順**（正答 **ウ**）
  図で扱う鍵配送方式では、サーバの公開鍵で保護して渡し、サーバ側の秘密鍵で復号する。実データの暗号化は共有した鍵を使う。 [図表・原本 p.20](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=20)

## 第8問

- <a name="q8-a"></a>**a IoTとエッジ処理**（正答 **イ**）
  エッジ処理では端末や近くのゲートウェイで処理できるので、すべての生データをデータセンターへ送る必要はない。 [原本 p.21](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=21)
- <a name="q8-b"></a>**b Webアプリの構成**（正答 **エ**）
  プレゼンテーション層は表示と入力。業務処理はロジック層、データの管理はデータ層。 [原本 p.21](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=21)
- <a name="q8-c"></a>**c オブジェクト指向**（正答 **ア**）
  オブジェクトはデータと操作をまとめた単位。メソッドはオブジェクトが備える操作を指す。 [原本 p.21](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=21)
- <a name="q8-d"></a>**d アプリ運用と可用性**（正答 **ウ**）
  複数のクラウドサービスを利用するのはマルチクラウド。ハイブリッドクラウドは通常、異なる種類の環境を連携させる構成を指す。 [原本 p.22](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=22)

## 第9問

- <a name="q9-a"></a>**a 電子メール**（正答 **ウ**）
  ブラウザとWebメールの画面はHTTP(S)、メール転送はSMTP、受信側がサーバ上のメールを扱うにはIMAPなどを使う。 [原本 p.23](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=23)
- <a name="q9-b"></a>**b クラウドファンディング**（正答 **ウ**）
  クラウドファンディングは広く支援者を募る資金調達。購入型・寄付型・投資型などで支援者が受け取るものが異なる。 [原本 p.23](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=23)
- <a name="q9-c"></a>**c フィンテックと金融商品**（正答 **エ**）
  プリペイドは先払い。後払いの信用決済と区別する。電子マネー残高の保管先とは別の話。 [原本 p.24](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=24)
- <a name="q9-d"></a>**d ネット広告**（正答 **ウ**）
  成果報酬型広告は購入・会員登録など事前に決めた成果が発生したときに費用が発生する。 [原本 p.24](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=24)

## 第10問

- <a name="q10-a"></a>**a ユーザー認証**（正答 **ウ**）
  チャレンジレスポンスでは毎回変わるチャレンジと秘密情報を使って応答を作る。パスワードそのものや固定の応答を毎回送る方式とは異なる。 [原本 p.25](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=25)
- <a name="q10-b"></a>**b 端末管理（MDM）**（正答 **イ**）
  MDMはアプリの導入可否、端末設定、紛失時の遠隔消去などを組織が管理する仕組み。 [原本 p.25](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=25)
- <a name="q10-c"></a>**c デジタルデバイド**（正答 **ウ**）
  デジタルデバイドとは、情報機器や接続へのアクセス、使いこなす能力の差によって生じる格差。 [原本 p.25](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=25)
- <a name="q10-d"></a>**d 個人情報保護法の対象**（正答 **ア**）
  個人情報保護法の「個人情報」は生存する個人に関する情報が対象。亡くなった人の情報でも、生存する遺族の情報を兼ねる場合は別途判断する。 [原本 p.26](https://www.cgarts.or.jp/wp-content/uploads/2025/07/exp_mm_25a.pdf#page=26)
