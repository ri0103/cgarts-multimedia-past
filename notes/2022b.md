## 第1問（共通問題）

- <a name="q1-1"></a>**（1） 著作者人格権と著作財産権**（正答 **ア**）
  著作者人格権には、いつ発表するか、誰の名で出すか、無断で内容を変えられないことに関する権利がある。 [原本 p.4](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=4)
- <a name="q1-2"></a>**（2） 許諾が要らない利用**（正答 **イ**）
  音楽の購入で得る利用範囲とWeb公開の権利は別。曲名や権利者名を書くだけで、自サイトのBGMに使えるようにはならない。 [原本 p.4](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=4)
- <a name="q1-3"></a>**（3） 著作権侵害**（正答 **ウ**）
  私的なコピーでも、コピーを防ぐ技術を解除して行えば、私的使用の例外の対象から外れる場合がある。 [原本 p.4](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=4)
- <a name="q1-4"></a>**（4） 商標権**（正答 **ウ**）
  商標は商品を示すマークとサービスを示すマークの両方を保護し、出所の識別に役立つ。 [原本 p.5](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=5)

## 第2問

- <a name="q2-a"></a>**a 眼球の構造**（正答 **オ**）
  図の順に、水晶体は焦点を調整し、虹彩は瞳孔の開き具合を調節する。網膜は光を受け、視神経はその信号を脳へ運ぶ。 [図表・原本 p.7](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=7)
- <a name="q2-b"></a>**b 音のマスキングなどの知覚**（正答 **エ**）
  大きい別の音で小さい音が聞こえにくくなるのはマスキング。雑音の中から特定の話し声を選べるのはカクテルパーティ効果。口の動きで別の音節に聞こえるのはマガーク効果。 [原本 p.7](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=7)
- <a name="q2-c"></a>**c 記憶の三過程**（正答 **ウ**）
  先に提示された項目が残りやすいのが初頭効果。最後の項目が残りやすいのは新近性効果。 [原本 p.8](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=8)
- <a name="q2-d"></a>**d 情報機器の使いやすさ**（正答 **イ**）
  使いやすさを評価する概念はユーザビリティ。インタラクションは利用者と機器の相互作用を指す。 [原本 p.8](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=8)

## 第3問

- <a name="q3-a"></a>**a 標本化・量子化とデータ量**（正答 **ア**）
  0.2秒間隔は毎秒5標本。8段階は1標本3ビットなので、5×3＝毎秒15ビット。 [図表・原本 p.9](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=9)
- <a name="q3-b"></a>**b 文書の作成とレイアウト**（正答 **ウ**）
  DTPは文字・図形・写真をPC上で配置して印刷用の版面を作る。部品の編集とページ全体のレイアウトを分けて考える。 [図表・原本 p.9](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=9)
- <a name="q3-c"></a>**c 音声波形とスペクトル**（正答 **ア**）
  フーリエ変換で音声波形から周波数成分を取り出せる。定常母音の繰り返し周期を逆数にすると基本周波数が得られる。 [原本 p.10](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=10)
- <a name="q3-d"></a>**d カラーモデル**（正答 **イ**）
  出力の際には共通色空間からプリンタ固有の色空間へ変換する。ICCプロファイルは機器の色空間との対応を表す。 [原本 p.10](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=10)

## 第4問

- <a name="q4-a"></a>**a 彩度対比**（正答 **イ**）
  背景が同じ色の鮮やかさの知覚を変えるのは彩度対比。色相対比とは、変わって見える属性が異なる。 [図表・原本 p.11](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=11)
- <a name="q4-b"></a>**b 印刷解像度**（正答 **エ**）
  dpiは1インチ当たりのドット数。印刷寸法をそのまま画素数として扱わない。 [原本 p.11](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=11)
- <a name="q4-c"></a>**c 画素の離散性と輪郭**（正答 **オ**）
  画素の格子で斜線や曲線を表すと段差が見え、ジャギーが生じる。アンチエイリアスは周辺画素の値で輪郭を滑らかに見せる。 [図表・原本 p.12](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=12)
- <a name="q4-d"></a>**d 形状の集合演算**（正答 **オ**）
  まずAからBに属する部分を取り除き、その結果にCを足す。どの処理を先に行うかで形が変わる。 [図表・原本 p.13](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=13)
- <a name="q4-e"></a>**e シェーディングの光成分**（正答 **ア**）
  面が多方向へ光を散らす成分が拡散反射。鏡のように特定方向へ強く返す鏡面反射と区別する。 [原本 p.13](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=13)

## 第5問

- <a name="q5-a"></a>**a RAID**（正答 **ウ**）
  RAID 0は高速化を目的とした分散で冗長性を持たない。RAID 1はミラー、RAID 5・6はパリティで障害に備える。 [原本 p.14](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=14)
- <a name="q5-b"></a>**b OSとアプリの役割分担**（正答 **ウ**）
  フレームワークに入力や通信などの共通処理を任せ、開発者はアプリ特有の部分を実装できる。 [図表・原本 p.15](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=15)
- <a name="q5-c"></a>**c サーバ仮想化**（正答 **イ**）
  コンテナはアプリの実行環境をパッケージ化し、通常は同じホストOSのカーネルを使って隔離する。 [原本 p.15](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=15)
- <a name="q5-d"></a>**d クラウドの提供範囲**（正答 **カ**）
  IaaSは計算機や回線の基盤、PaaSは開発・実行環境、SaaSは完成アプリ。提供者がどの層まで管理するかを見る。 [図表・原本 p.16](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=16)

## 第6問

- <a name="q6-a"></a>**a プログラムの反復処理**（正答 **ウ**）
  繰り返し使える処理単位が関数。入力は引数、処理結果は戻り値。再利用する関数群はライブラリにまとめられる。 [原本 p.17](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=17)
- <a name="q6-b"></a>**b UMLによる設計**（正答 **ア**）
  クラス図はクラスの属性・操作・関係を表す。処理の時間順を示すシーケンス図とは目的が違う。 [図表・原本 p.17](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=17)
- <a name="q6-c"></a>**c データベースの分類**（正答 **イ**）
  キーバリューストアはキーを指定した参照に適する。他の項目まで何でも高速に検索できるとは限らない。 [原本 p.18](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=18)
- <a name="q6-d"></a>**d ロックとトランザクション**（正答 **エ**）
  トランザクションは複数の更新をまとめて扱う単位。ロックは並行処理中に他の処理が競合する操作を行うのを制御する。 [原本 p.18](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=18)

## 第7問

- <a name="q7-a"></a>**a TCP/IPの階層**（正答 **イ**）
  TCP/IPではアプリ層にHTTPなど、トランスポート層にTCP/UDP、インターネット層にIP、リンク層にEthernetなどがある。 [図表・原本 p.19](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=19)
- <a name="q7-b"></a>**b DNS**（正答 **イ**）
  DNSの名前空間は階層型。委任されたドメインの管理者は、自分の配下にサブドメインを設定できる。 [原本 p.19](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=19)
- <a name="q7-c"></a>**c 無線通信の規格**（正答 **オ**）
  NFCはごく近距離、Bluetoothは周辺機器などの近距離、Wi-Fiは無線LAN、携帯回線は基地局経由の広域通信。 [原本 p.20](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=20)
- <a name="q7-d"></a>**d 通信のセキュリティ対策**（正答 **ウ**）
  プロキシはキャッシュに加え、通信先や内容のフィルタリング、ログ取得などにも使える。 [原本 p.20](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=20)

## 第8問

- <a name="q8-a"></a>**a 音声対話アプリの構成**（正答 **ウ**）
  音声対話では入力音を認識して文字や意味に変換し、アプリで回答を作り、その回答を音声合成で読み上げる。 [図表・原本 p.21](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=21)
- <a name="q8-b"></a>**b Webアプリの構成**（正答 **エ**）
  三層構成の表示はプレゼンテーション層。クライアントは要求を出し、サーバは要求を処理して応答を返す。 [原本 p.21](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=21)
- <a name="q8-c"></a>**c アプリのテスト**（正答 **イ**）
  部品単体の挙動、部品間の結合、同時利用などの負荷の順に、何を確かめるテストかを見分ける。 [原本 p.22](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=22)
- <a name="q8-d"></a>**d 冗長化**（正答 **ア**）
  アクティブ／アクティブは複数台が平常時に処理を分担する。待機系だけを用意する構成では故障時に切り替える。 [図表・原本 p.22](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=22)

## 第9問

- <a name="q9-a"></a>**a URLとHTTP・HTTPS**（正答 **イ**）
  URL先頭のhttpやhttpsはスキーム。ホスト名やパスとは違い、資源へのアクセス方法を指定する。 [原本 p.23](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=23)
- <a name="q9-b"></a>**b Webメールの経路**（正答 **ア**）
  ブラウザはWebメール画面とHTTP(S)で通信し、他のメールサーバとの配送にはSMTPなどを使う。 [図表・原本 p.23](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=23)
- <a name="q9-c"></a>**c プリペイド型電子マネー**（正答 **ア**）
  プリペイド式のICカードは利用前に残高を入金し、支払いのたびに残高を減らす。 [原本 p.24](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=24)
- <a name="q9-d"></a>**d ネットビジネス**（正答 **エ**）
  ホスティングは事業者のサーバなどを借りる。ハウジングは機器を持ち込んで設置場所や回線を借りる。 [原本 p.24](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=24)

## 第10問

- <a name="q10-a"></a>**a ユニキャスト配信**（正答 **エ**）
  ユニキャストでは受信者ごとのデータの流れを作れる。オンデマンド再生なら各人の一時停止や早送りにも応じられる。 [原本 p.25](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=25)
- <a name="q10-b"></a>**b 交通を支援する情報技術**（正答 **ア**）
  ITSは情報通信による交通支援全般。GPSは測位、ETCは通行料金の自動支払い、道路情報の配信は交通案内の役割を持つ。 [原本 p.25](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=25)
- <a name="q10-c"></a>**c デジタルデバイド**（正答 **イ**）
  情報技術への接続や利用技能の差が、情報取得、教育、就業などの機会へ波及するのがデジタルデバイド。 [原本 p.26](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=26)
- <a name="q10-d"></a>**d 端末管理（MDM）**（正答 **ウ**）
  MDMではアプリの導入制限や遠隔ロック・消去を行える。利用者がすべて自由にインストールできる仕組みとは目的が異なる。 [原本 p.26](https://www.cgarts.or.jp/v1/kentei/past/img/2022_11/t/e/exp_mm_22b.pdf#page=26)
