## 第1問（共通問題）

- <a name="q1-1"></a>**（1） 著作権の種類**（正答 **ア**）
  著作財産権や著作隣接権は譲渡できる。著作者人格権は著作者本人に帰属し、譲渡できない。 [原本 p.4](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=4)
- <a name="q1-2"></a>**（2） 著作者と共同著作**（正答 **ア**）
  共同著作物の共有著作権を行使するには、原則として共有者全員の合意が要る。 [原本 p.4](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=4)
- <a name="q1-3"></a>**（3） 撮影で入り込んだ音楽の利用**（正答 **ウ**）
  撮影対象に付随して軽微に入ったBGMは、一定の条件下では「写り込み」の対象になり得る。後から曲を主役として追加する場合は別に考える。 [原本 p.4](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=4)
- <a name="q1-4"></a>**（4） 特許・実用新案・意匠・商標**（正答 **エ**）
  特許・実用新案・意匠・商標はいずれも権利取得に向けて特許庁へ出願する。著作権は原則として創作時に発生する。 [原本 p.5](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=5)

## 第2問

- <a name="q2-a"></a>**a 画像変換の識別**（正答 **ウ**）
  明度を下げると輪郭や色相はおおむね保ったまま全体が暗くなる。階調変換のトーンカーブは入力値と出力値の関係を表す。 [図表・原本 p.8](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=8)
- <a name="q2-b"></a>**b 色相対比**（正答 **イ**）
  色相対比では背景との色味の違いが強調される。中央の図形の画素値が同じでも見え方は変わる。 [図表・原本 p.10](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=10)
- <a name="q2-c"></a>**c ベクタ画像**（正答 **エ**）
  ベクタ形式は線や曲線などを座標や数式で持つ。ラスタ形式は画素の格子を持つ。 [原本 p.10](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=10)
- <a name="q2-d"></a>**d 画面表示と印刷の色差**（正答 **イ**）
  CMYKのMはマゼンタ。印刷結果からこの成分が抜けると緑寄りになり、赤や紫の再現にも影響する。 [図表・原本 p.11](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=11)
- <a name="q2-e"></a>**e 見えない線や面の除去**（正答 **エ**）
  隠線・隠面消去で手前の形状に遮られた線や面を除くと、物体どうしの前後関係が分かる。 [図表・原本 p.11](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=11)

## 第3問

- <a name="q3-a"></a>**a 波形と音の三要素**（正答 **エ**）
  波形の振幅は音の大きさ、周期の逆数は音の高さ、形は音色の判断材料。同じ形で周期だけ違えば、同じ楽器の異なる音程と考えられる。 [図表・原本 p.12](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=12)
- <a name="q3-b"></a>**b 記憶とリハーサル**（正答 **ウ**）
  記憶は感覚・短期・長期に分けて考えられる。復唱による維持と、知識に関連づける精緻化を区別する。 [原本 p.13](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=13)
- <a name="q3-c"></a>**c インタフェースのメタファ**（正答 **ウ**）
  書類・フォルダ・ごみ箱のように、身近なものの仕組みを画面操作に借りる設計がメタファ。 [原本 p.13](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=13)
- <a name="q3-d"></a>**d VRの三要素**（正答 **エ**）
  VRの三要素は三次元の空間性、実時間の相互作用、自己投射性。空間・操作への反応・自分がそこにいる感覚を対応させる。 [原本 p.13](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=13)

## 第4問

- <a name="q4-a"></a>**a A/D変換**（正答 **エ**）
  標本化は時間方向に点を取る操作、量子化は各点の振幅を段階に丸める操作。図では0.5秒に8標本分あるので16 Hz。量子化は3ビットなので8段階。 [図表・原本 p.14](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=14)
- <a name="q4-b"></a>**b 転送時間と圧縮後の容量**（正答 **ウ**）
  54 Mbps×4秒÷8＝27 MB。432 MBから27 MBにするには元の16分の1以下に圧縮する。 [原本 p.14](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=14)
- <a name="q4-c"></a>**c フォントの見分け方**（正答 **ウ**）
  書体の骨格が同じで太さなどが異なれば同じファミリと判断できる。図では〈3〉と〈4〉が該当する。 [図表・原本 p.15](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=15)
- <a name="q4-d"></a>**d 可視光と色の知覚**（正答 **ア**）
  可視光は人の目が感じ取れる電磁波。赤外線は可視域より長波長で、紫外線は短波長。 [原本 p.15](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=15)

## 第5問

- <a name="q5-a"></a>**a ハードウェアの構成**（正答 **ウ**）
  周辺機器の接続にはUSBなどの標準規格が使われる。CPU・メモリ・補助記憶装置・入出力の役割も分けて考える。 [原本 p.16](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=16)
- <a name="q5-b"></a>**b CPUの動作**（正答 **イ**）
  起動直後は機器上の不揮発メモリにあるファームウェアが動き、その後にブートローダやOSが読み込まれる。 [原本 p.16](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=16)
- <a name="q5-c"></a>**c OS上でのアプリ動作**（正答 **ウ**）
  静的リンクは必要なコードを実行ファイルに組み込む。動的リンクは共有ライブラリを実行時などに読み込む。 [原本 p.17](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=17)
- <a name="q5-d"></a>**d デスクトップ仮想化**（正答 **エ**）
  VDIでは作業環境がサーバ側にあるため、別の端末からでも自分の環境にアクセスできる。 [原本 p.17](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=17)

## 第6問

- <a name="q6-a"></a>**a ネット上の資源を指す記法**（正答 **エ**）
  URLは資源の場所やアクセス方法を表す。ドメイン名はその一部分で、URL全体と同義ではない。 [原本 p.18](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=18)
- <a name="q6-b"></a>**b DNS**（正答 **ア**）
  DNSは分散・階層型。ドメインに対応するIPを変更する際には、そのゾーンを管理する権威DNSのレコードを更新する。 [原本 p.18](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=18)
- <a name="q6-c"></a>**c LANとWANなどのネットワーク**（正答 **ア**）
  建物など限られた範囲はLAN、遠隔拠点のLANを接続する広域網はWAN。中継する装置の役割も見分ける。 [原本 p.18](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=18)
- <a name="q6-d"></a>**d ルーティング**（正答 **ア**）
  距離ベクトル型では隣接ルータから宛先までの距離情報を受け取る。リンク状態型ではネットワーク構造を把握して経路を計算する。 [原本 p.19](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=19)

## 第7問

- <a name="q7-a"></a>**a 署名などのセキュリティ技術**（正答 **イ**）
  デジタル署名は署名者の秘密鍵で生成し、公開鍵で検証する。署名は改ざん検知に使え、内容の秘匿には別途暗号化が必要。 [原本 p.20](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=20)
- <a name="q7-b"></a>**b ボットと不正通信**（正答 **ア**）
  DDoSは分散した送信元からの過負荷で正規のサービス利用を妨げる。無断でシステムへ入り込む行為は、この設問ではクラッキングと呼んでいる。 [図表・原本 p.20](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=20)
- <a name="q7-c"></a>**c 機密データの保護**（正答 **ウ**）
  VPNの暗号化された経路を使うと、通信途中の盗聴や改ざんのリスクを下げられる。 [原本 p.21](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=21)
- <a name="q7-d"></a>**d 組織のセキュリティと事業継続**（正答 **ウ**）
  通信はTLSやIPsecで保護できる。災害時の復旧にはバックアップや代替設備など事業継続の対策が必要。 [原本 p.21](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=21)

## 第8問

- <a name="q8-a"></a>**a 開発のコンセプト設計**（正答 **イ**）
  要望書の文言をそのまま仕様にせず、なぜ必要かを確認し、対象ユーザー・解決課題・優先順位を言語化する。 [原本 p.22](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=22)
- <a name="q8-b"></a>**b アプリの三層構成**（正答 **ア**）
  三層構成ではプレゼンテーション層が表示と入力、ロジック層が業務処理、データ層が格納や取得を担当する。 [原本 p.22](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=22)
- <a name="q8-c"></a>**c 冗長化の構成と特徴**（正答 **ウ**）
  アクティブ／アクティブは複数台が平常時も処理する。アクティブ／スタンバイでは通常は稼働系が処理し、障害時に待機系へ切り替える。 [図表・原本 p.23](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=23)
- <a name="q8-d"></a>**d 開発時の法規・ライセンス・テスト**（正答 **イ**）
  単体・結合テストには自動化できる部分があり、再実行を速くできる。既存ライブラリは利用条件も確認する。 [原本 p.23](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=23)

## 第9問

- <a name="q9-a"></a>**a Webメールの経路**（正答 **オ**）
  ブラウザとWebメールの間はHTTP(S)。図の受信サーバとの接続はPOP/IMAP、送信サーバとの接続はSMTP。 [図表・原本 p.24](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=24)
- <a name="q9-b"></a>**b Cookieに保存する情報**（正答 **ア**）
  CookieはセッションIDなどの小さなデータを保存する。JavaScriptはページを動かすコードで、Cookieの通常の保存用途ではない。 [原本 p.24](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=24)
- <a name="q9-c"></a>**c SaaSの利用例**（正答 **ウ**）
  完成したグループウェアなどをサービスとして使う形がSaaS。PaaSは実行環境、IaaSは計算機・ネットワークなどの基盤を提供する。 [原本 p.25](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=25)
- <a name="q9-d"></a>**d ネット広告**（正答 **ウ**）
  検索語連動はリスティング。広告料の条件には掲載期間、表示数、クリック数、購入などの成果があり、何に課金するかを見分ける。 [原本 p.25](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=25)

## 第10問

- <a name="q10-a"></a>**a 生活に使われるICT**（正答 **ウ**）
  フィンテックは金融サービスへのIT活用。スマホ決済など、具体例を目的と結びつける。 [原本 p.26](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=26)
- <a name="q10-b"></a>**b 映像配信方式**（正答 **ア**）
  ユニキャストは受信先ごとに送る。マルチキャストはグループ向けで、経路の分岐点で複製できる。 [原本 p.26](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=26)
- <a name="q10-c"></a>**c 携帯端末の通信サービス**（正答 **ア**）
  VoIPは音声をパケット化してIP網で送る。IP電話や音声通話アプリで使われる。 [原本 p.27](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=27)
- <a name="q10-d"></a>**d プライバシーポリシー**（正答 **エ**）
  プライバシーポリシーは個人情報を何のために取得し、どう扱うかを利用者に示す方針。認証マークそのものではない。 [原本 p.27](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/exp_mm_25b.pdf#page=27)
