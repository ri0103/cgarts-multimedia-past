## 第1問（共通問題）

- <a name="q1-1"></a>**（1） 複製権**（正答 **ウ**）
  複製権は作品をコピーする行為に関わる基本的な著作財産権。紙への印刷やデジタル保存など、媒体は一つに限られない。 [原本 p.4](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=4)
- <a name="q1-2"></a>**（2） ゲームソフトと知的財産権**（正答 **ア**）
  プログラムの具体的表現は著作権の対象になり得る。処理の手順やアルゴリズム自体とは区別する。 [原本 p.4](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=4)
- <a name="q1-3"></a>**（3） 著作権の保護期間**（正答 **エ**）
  団体名義の著作物の保護期間は、公表された作品なら原則として公表後70年。個人著作の原則は著作者の死後70年。 [原本 p.4](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=4)
- <a name="q1-4"></a>**（4） 知的財産法と保護対象**（正答 **イ**）
  特許は発明、実用新案は物品の形や構造などの考案、意匠はデザイン、商標は商品・サービスを識別する標識に対応する。 [原本 p.5](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=5)

## 第2問

- <a name="q2-1"></a>**（1） 人と道具の使いやすさ**（正答 **ク**）
  人間工学では身体寸法や負荷といった物理的・生理的特性を道具の設計に取り入れる。情報システムの覚えやすさや理解しやすさは認知特性と結びつく。 [原本 p.8](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=8)
- <a name="q2-2a"></a>**（2）a 波形から読み取る音の特徴**（正答 **カ**）
  短周期の波のほうが音は高い。拡大・縮小しても波の形が対応するなら、同じ楽器の異なる音程として説明できる。 [図表・原本 p.9](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=9)
- <a name="q2-2b"></a>**（2）b 周期から求める周波数**（正答 **ア**）
  周期2 ms＝0.002秒。周波数はその逆数なので500 Hz。 [図表・原本 p.9](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=9)
- <a name="q2-3"></a>**（3） インタフェースのメタファ**（正答 **ア**）
  フォルダやごみ箱のように、既に知っている物や仕組みに置き換えて操作を理解させるのがメタファ。 [原本 p.10](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=10)

## 第3問

- <a name="q3-a"></a>**a パッケージ系とネットワーク系のメディア**（正答 **ウ**）
  記録媒体で配るパッケージ系は物理媒体の容量や流通に依存する。ネットワーク系は配信回線や受信側の帯域に依存する。 [原本 p.11](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=11)
- <a name="q3-b"></a>**b A/D変換**（正答 **オ**）
  波形から標本間隔を読む。この設問では0.1秒おきなので10 Hz。量子化3ビットは8段階を表せる。 [図表・原本 p.11](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=11)
- <a name="q3-c"></a>**c タイポグラフィ**（正答 **エ**）
  文字ごとに幅が違うのはプロポーショナル。欧文のストローク先端の飾りがセリフで、それを省く書体はサンセリフ。 [図表・原本 p.12](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=12)
- <a name="q3-d"></a>**d 色の三属性と知覚**（正答 **エ**）
  可視光は目で感じられる電磁波の範囲。赤外線は可視光より長い波長に位置する。 [原本 p.12](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=12)

## 第4問

- <a name="q4-a"></a>**a 周囲の色と色の見え方**（正答 **ア**）
  周囲の色の違いで同じ色が違って見えるのは対比。背景との差と、図形自体の画素値を分けて考える。 [図表・原本 p.13](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=13)
- <a name="q4-b"></a>**b グレースケールと画素値**（正答 **ク**）
  8ビットのグレースケールは256段階。一般に0が黒で255が白。画像の座標を横・縦で追い、各位置の値を明暗として読む。 [原本 p.13](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=13)
- <a name="q4-c"></a>**c カメラワーク**（正答 **エ**）
  被写体へ近づく・離れるためにカメラを動かすのがドリー。その場でカメラを横に振るのがパン。レンズで画角を変えるのがズーム。 [図表・原本 p.15](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=15)
- <a name="q4-d"></a>**d ラスタとベクタ**（正答 **エ**）
  ラスタは各画素を持つので画素単位の濃淡処理に向く。変形時には補間が必要で、斜め線のギザギザなどが生じ得る。 [原本 p.16](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=16)
- <a name="q4-e"></a>**e 転送時間と圧縮後の容量**（正答 **ウ**）
  64 Mbps×8秒÷8＝64 MB。512 MBから64 MB以下にするには8分の1以下に圧縮する。 [原本 p.16](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=16)

## 第5問

- <a name="q5-a"></a>**a CPUの動作**（正答 **イ**）
  電源投入直後に動くファームウェアは通常、機器の不揮発メモリ上にある。その初期処理を経て補助記憶装置からOSが読み込まれる。 [原本 p.17](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=17)
- <a name="q5-b"></a>**b GPU**（正答 **ウ**）
  GPUは画像処理などを並列に進めるプロセッサ。一般の命令実行を担うCPUと役割を比較する。 [図表・原本 p.17](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=17)
- <a name="q5-c"></a>**c ソフトウェアの階層**（正答 **イ**）
  ソフトウェアライブラリの再利用は、開発期間の短縮や実績のある機能の利用につながる。 [図表・原本 p.18](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=18)
- <a name="q5-d"></a>**d クラウドサービス**（正答 **イ**）
  クラウドでも災害対策は必要。データのバックアップと復旧方法は利用者と事業者の分担に沿って設計する。 [原本 p.18](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=18)

- <a name="q6-c"></a>**c プログラミング言語**（正答 **イ**）

- <a name="q6-d"></a>**d データベースの種類**（正答 **イ**）

## 第7問

- <a name="q7-a"></a>**a プロトコルの用途**（正答 **エ**）
  SMTPはメールの送信やサーバ間転送。端末がサーバからメールを受け取る用途はPOPやIMAPで区別する。 [原本 p.21](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=21)
- <a name="q7-b"></a>**b インターネット接続事業者**（正答 **イ**）
  FTTHは加入者宅まで光ファイバーで接続する方式。宅内のWi-Fiとは別の区間を指す。 [図表・原本 p.21](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=21)
- <a name="q7-c"></a>**c ルーティング**（正答 **エ**）
  距離ベクトル型は隣のルータから得た距離情報で経路表を更新する。リンク状態型と区別する。 [原本 p.22](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=22)
- <a name="q7-d"></a>**d 移動に伴う基地局の切り替え**（正答 **イ**）
  1つの基地局が受け持つ範囲がセル。端末がセルの間を移動するとき、通信を維持して接続先を替えるのがハンドオーバ。 [図表・原本 p.22](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=22)

## 第8問

- <a name="q8-a"></a>**a IoT**（正答 **ア**）
  機器やセンサをネットで結び、状態の取得や制御に利用する考え方がIoT。例ではセンサの情報が冷蔵庫の運転制御に使われる。 [原本 p.23](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=23)
- <a name="q8-b"></a>**b ビッグデータ解析**（正答 **イ**）
  ビッグデータ解析にはクラウドや複数台の分散処理も使える。スーパーコンピュータが常に必要なわけではない。 [原本 p.23](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=23)
- <a name="q8-c"></a>**c 開発のコンセプト設計**（正答 **ウ**）
  利用者の場面を想定するシナリオ分析で違和感や難所を洗い出す。顧客の要望と実際の利用者の課題の両方を見る。 [原本 p.24](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=24)
- <a name="q8-d"></a>**d 可用性と冗長化**（正答 **ウ**）
  障害時に待機側へ切り替えるのはフェイルオーバ。フェイルセーフは故障しても安全側の状態に移る考え方。 [原本 p.24](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=24)

## 第9問

- <a name="q9-a"></a>**a WebコンテンツとCookie**（正答 **ア**）
  Cookieは小さな情報をブラウザに保存する仕組み。動的Webコンテンツはユーザー入力や状態によって変化する。 [原本 p.25](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=25)
- <a name="q9-b"></a>**b コミュニケーションサービス**（正答 **エ**）
  ソーシャルタギングは利用者が情報にタグを付ける。人同士のつながりはソーシャルグラフで表現できる。 [原本 p.25](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=25)

## 第10問

- <a name="q10-a"></a>**a インターネット上の犯罪**（正答 **カ**）
  偽の案内で情報をだまし取るのがフィッシング。システムへの不正侵入はこの設問ではクラッキング、分散した送信元からサービスを過負荷にするのはDDoS。 [原本 p.27](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=27)
- <a name="q10-b"></a>**b セキュリティと事業継続**（正答 **ウ**）
  業務を続けるには災害前にBCPを定める。通信の盗聴・改ざんを防ぐ対策はTLSやIPsecなどで行う。 [原本 p.27](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=27)
- <a name="q10-c"></a>**c ネット上のモラルとマナー**（正答 **イ**）
  SNSの閲覧者は想定した知人に限らない。他人の情報や第三者の投稿を扱う際は公開範囲と権利を確認する。 [原本 p.28](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=28)
- <a name="q10-d"></a>**d プライバシーポリシー**（正答 **ア**）
  プライバシーポリシーは利用者の個人情報をどう取得・利用・管理するかを明示する方針。 [原本 p.28](https://www.cgarts.or.jp/v1/kentei/past/img/2023_07/t/e/exp_mm_23a.pdf#page=28)
