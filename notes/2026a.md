## 第1問（共通問題）

- <a name="q1-1"></a>**（1） 著作権の内訳**（正答 **エ**、2.5点）
  著作者に財産権と人格権が生じる。実演家・レコード製作者・放送事業者などの権利は著作隣接権。 [原本 p.4](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=4)
- <a name="q1-2"></a>**（2） 利用許諾の例外**（正答 **イ**、2.5点）
  展示会の撮影許可が、その写真をWeb公開する許可まで含むとは限らない。出典リンクだけでは許諾の代わりにならない。 [原本 p.4](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=4)
- <a name="q1-3"></a>**（3） 職務著作**（正答 **イ**、2.5点）
  要件を満たす職務著作では法人が著作者になり得る。プログラムも対象で、公表名義の要件に特則がある。 [原本 p.5](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=5)
- <a name="q1-4"></a>**（4） 産業財産権**（正答 **キ**、2.5点）
  特許は発明、実用新案は物品の形や構造等の考案、意匠はデザイン、商標は識別標識。特許の存続期間は原則として出願から20年。 [原本 p.5](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=5)

## 第2問

- <a name="q2-a"></a>**a 色の同化**（正答 **ウ**、2点）
  周囲の色に近づいて見えるのが同化、違いが強調されるのが対比。例えば赤いネットの中のミカンは赤みが増して見えやすい。 [原本 p.8](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=8)
- <a name="q2-b"></a>**b 画素数と画像容量**（正答 **オ**、2点）
  解像度を両辺に掛けて300×200画素。RGB各8ビットなので、非圧縮なら300×200×3＝180,000バイト。 [図表・原本 p.8](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=8)
- <a name="q2-c"></a>**c 画像合成**（正答 **カ**、2点）
  マスク処理では、白なら入力1、黒なら入力2から画素を取る。この設問では図3の〈2〉。一般化すると合成値は α×画像1＋(1−α)×画像2。 [図表・原本 p.9](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=9)
- <a name="q2-d"></a>**d ヒストグラムと二値化**（正答 **ア**、2点）
  明るさのしきい値で白黒を分ける。元画像と二値画像を見比べ、白になる領域と黒になる領域の境界を探す。この設問のしきい値は図6の①。 [図表・原本 p.10](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=10)
- <a name="q2-e"></a>**e シェーディングの光成分**（正答 **ア**、2点）
  拡散反射の強さは主に光源と面の角度で決まる。鏡面反射のハイライトは視点を動かすと位置が変わる。 [図表・原本 p.11](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=11)

## 第3問

- <a name="q3-a"></a>**a 短期記憶**（正答 **ウ**、2.5点）
  初頭効果は列の最初、新近性効果は最後が思い出しやすいこと。復唱は維持、意味づけや関連づけは精緻化リハーサル。 [原本 p.12](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=12)
- <a name="q3-b"></a>**b 音の知覚**（正答 **イ**、2.5点）
  騒音の中で聞きたい話し声を選べるのはカクテルパーティ効果。別の音で聞こえなくなるマスキングとは区別する。 [原本 p.12](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=12)
- <a name="q3-c"></a>**c 情報機器の使いやすさ**（正答 **ア**、2.5点）
  使いやすさはユーザビリティ。インタラクションは人と機器とのやり取りを指す。 [原本 p.13](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=13)
- <a name="q3-d"></a>**d 明度の勾配と知覚**（正答 **ウ**、2.5点）
  マッハ効果により、明度がなだらかに変わる部分の両端で明るさが帯状に強調される。物理的な明度と知覚を区別する。 [図表・原本 p.13](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=13)

<a name="q4"></a>

## 第4問

- <a name="q4-a"></a>**a 標本化・量子化とデータ量**（正答 **ア**、2.5点）
  10標本/ms＝10,000標本/秒。16段階なら1標本4ビットなので、非圧縮で40,000 bit/s。 [図表・原本 p.15](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=15)
- <a name="q4-b"></a>**b Unicode**（正答 **ウ**、2.5点）
  コードポイントは文字を識別する番号で、UTF-8などはその番号をバイト列にする方式。U+に続く16進桁数は常に4桁とは限らない。 [原本 p.15](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=15)
- <a name="q4-c"></a>**c 音声合成と認識**（正答 **イ**、2.5点）
  音声認識は音から文字へ、音声合成は文字などから音へ。比較条件が同じなら、区切りが明示されない連続音声は単語単位より扱いにくい。 [原本 p.16](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=16)
- <a name="q4-d"></a>**d 表色系**（正答 **ウ**、2.5点）
  色合わせの共通基準にはCIE XYZやLabなどを使える。機器固有のRGBの数値をそのまま別の機器へ送っても同じ色にはならない。 [原本 p.16](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=16)

## 第5問

- <a name="q5-a"></a>**a RAID**（正答 **エ**、2.5点）
  RAID 0は分散書き込みで冗長性なし、1はミラー、5は分散パリティ、6は二重パリティ。 [原本 p.17](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=17)
- <a name="q5-b"></a>**b OSの役割**（正答 **イ**、2.5点）
  OSは計算資源や入出力を管理する。PCだけでなく家電や車載機器にも組み込まれる。 [原本 p.17](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=17)
- <a name="q5-c"></a>**c サーバ仮想化**（正答 **ウ**、2.5点）
  コンテナはアプリと依存関係をまとめ、通常はホストのカーネルを共有しながら隔離する。VMはゲストOSを持てる。 [原本 p.18](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=18)
- <a name="q5-d"></a>**d クラウドとオンプレミス**（正答 **イ**、2.5点）
  クラウドも障害に備える必要がある。バックアップ、冗長化、復旧手順はサービスごとの責任分担を確認する。 [原本 p.18](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=18)

## 第6問

- <a name="q6-a"></a>**a TCP/IP**（正答 **イ**、2.5点）
  IPはパケットの配送、TCPは順序制御・再送などによる信頼性を担当する。 [原本 p.19](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=19)
- <a name="q6-b"></a>**b IPアドレス**（正答 **ウ**、2.5点）
  NATはアドレスを変換する。NAPTではポートも使い、複数端末で1つの外部アドレスを共有できる。 [原本 p.19](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=19)
- <a name="q6-c"></a>**c インターネット接続方式**（正答 **エ**、2.5点）
  メッシュWi-Fiは複数のアクセスポイントで範囲を広げる。有線LANの代表的な規格はEthernet。 [原本 p.19](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=19)
- <a name="q6-d"></a>**d 基地局と携帯端末**（正答 **ウ**、2.5点）
  移動中に接続先の基地局を切り替えて通信を続けることをハンドオーバという。 [図表・原本 p.20](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=20)

## 第7問

- <a name="q7-a"></a>**a TLSの通信手順**（正答 **ウ**、2.5点）
  TLSでは証明書でサーバの身元を確認し、鍵を確立して以後の通信を共通鍵で保護する。図の鍵配送は特定方式の例で、現行TLSすべてに共通する手順ではない。 [図表・原本 p.21](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=21)
- <a name="q7-b"></a>**b VPNと暗号化**（正答 **ア**、2.5点）
  インターネットVPNは公衆回線上に論理的な経路を作るため、回線混雑の影響を受け得る。 [原本 p.22](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=22)
- <a name="q7-c"></a>**c 多要素認証と多段階認証**（正答 **エ**、2.5点）
  手順を複数回に分けるのが多段階、知識・所持・生体など異なる種類を組み合わせるのが多要素。パスワードとSMSコードは試験上、知識と所持に当たる。 [原本 p.22](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=22)
- <a name="q7-d"></a>**d マルウェアの分類**（正答 **イ**、2.5点）
  ひそかに情報を集めるのはスパイウェア、身代金を求めるのはランサムウェア、有用なソフトを装うのはトロイの木馬。 [原本 p.22](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=22)

## 第8問

- <a name="q8-a"></a>**a IoTシステム**（正答 **イ**、2.5点）
  エッジ処理を使うと、IoT端末や近くの機器で集約・判定できる。全データを遠隔サーバに送らず、遅延や通信量を抑えられる。 [原本 p.23](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=23)
- <a name="q8-b"></a>**b Webアプリの階層構成**（正答 **エ**、2.5点）
  バックエンドはサーバ側で処理する部分。静的コンテンツは用意された内容を返し、動的コンテンツは入力や状態に応じて生成される。 [原本 p.23](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=23)
- <a name="q8-c"></a>**c アプリの企画とデザイン**（正答 **ウ**、2.5点）
  基本設計で機能と画面の概要を決め、詳細設計で画面動作や処理の仕様を詰める。 [原本 p.24](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=24)
- <a name="q8-d"></a>**d オブジェクト指向**（正答 **ウ**、2.5点）
  データと操作をひとまとまりにするのがオブジェクト。内部を隠し、決めた窓口から操作させるのがカプセル化。 [原本 p.24](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=24)

## 第9問

- <a name="q9-a"></a>**a 電子メール**（正答 **ウ**、2.5点）
  宛先を他の受信者に見せたくないときはBCCを使う。CCの宛先は通常表示される。 [原本 p.25](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=25)
- <a name="q9-b"></a>**b ネット事業の支援サービス**（正答 **イ**、2.5点）
  この出題のO2Oはオンラインの情報やクーポンを起点に実店舗へ誘導する施策。決済代行は複数の決済手段をまとめて扱う。 [原本 p.25](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=25)
- <a name="q9-c"></a>**c 金融サービス**（正答 **ウ**、2.5点）
  プリペイドは先に入金する方式という意味。残高がサーバにあるかICカードにあるかは別の分類軸。 [原本 p.26](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=26)
- <a name="q9-d"></a>**d オウンドメディア**（正答 **キ**、2.5点）
  自社で発信と管理を行う媒体がオウンドメディア。紙の案内、自社サイト、メールマガジンなどが該当する。 [原本 p.26](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=26)

## 第10問

- <a name="q10-a"></a>**a 放送型の映像配信**（正答 **イ**、2.5点）
  ブロードキャストは同じ映像を不特定多数へ一斉配信する。各利用者が別の時点から再生する方式とは違う。 [原本 p.27](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=27)
- <a name="q10-b"></a>**b シンクライアント**（正答 **イ**、2.5点）
  シンクライアントではデータや主な処理をサーバ側に集め、端末には画面表示や入力などを担当させる。 [原本 p.27](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=27)
- <a name="q10-c"></a>**c 情報漏えい対策**（正答 **カ**、2.5点）
  MDMは端末設定や紛失時の消去を管理する。VDIは作業環境をサーバ側に置き、端末へのデータ残存を減らせる。 [原本 p.28](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=28)
- <a name="q10-d"></a>**d 情報リテラシー**（正答 **カ**、2.5点）
  出典と根拠を確かめてから情報を使う。他者の文章を自分の成果のように扱うと剽窃になる。OSS利用時もライセンスを確認する。 [原本 p.28](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/exp_mm_26a.pdf#page=28)
