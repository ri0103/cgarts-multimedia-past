## 第1問（共通問題）

- <a name="q1-1"></a>**（1） 公衆送信権**（正答 **ウ**）
  楽曲を不特定多数にインターネット配信する行為には公衆送信権が関わる。翻訳や複製と区別する。 [原本 p.4](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=4)
- <a name="q1-2"></a>**（2） 著作物の利用**（正答 **イ**）
  私的使用のための複製にも例外がある。違法に配信されたと知って行う一定のダウンロードやコピー防止技術の回避は、私的使用を理由に当然には認められない。 [原本 p.4](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=4)
- <a name="q1-3"></a>**（3） 著作権侵害**（正答 **イ**）
  作風・画風のような抽象的な特徴と、具体的な創作表現を区別する。元作品への依拠や具体的表現の類似が判断材料。 [原本 p.4](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=4)
- <a name="q1-4"></a>**（4） 不正競争防止法**（正答 **イ**）
  不正競争防止法は営業秘密の不正取得や混同を生む表示などの不正競争を規制する。創作物すべてに期間付きの独占権を与える制度ではない。 [原本 p.5](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=5)

## 第2問

- <a name="q2-a"></a>**a 単眼による奥行きの表現**（正答 **ア**）
  重なりでは手前の物が奥を隠し、線遠近法では平行線が遠方で収束して見える。片目でもこれらを使って奥行きを推測できる。 [原本 p.8](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=8)
- <a name="q2-b"></a>**b 記憶と想起**（正答 **ウ**）
  初めと終わりが中間より記憶に残りやすい。前は初頭効果、後ろは新近性効果。想起する際は手がかりの有無がポイント。 [原本 p.8](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=8)
- <a name="q2-c"></a>**c 人とコンピュータの対話**（正答 **エ**）
  マルチモーダルUIは音声や視覚など複数のモダリティを利用する。物の形が可能な操作を示唆する考え方はアフォーダンス。 [原本 p.9](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=9)
- <a name="q2-d"></a>**d VR**（正答 **エ**）
  VRでは利用者の動きに応じて表示が変わることや、物体の衝突にもっともらしい反応が返ることが、空間の実在感につながる。 [原本 p.9](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=9)

## 第3問

- <a name="q3-a"></a>**a 印刷画像の画素数**（正答 **エ**）
  25.4 mm＝1インチなので127×76.2 mmは5×3インチ。350 dpiを掛けると1,750×1,050画素。 [原本 p.10](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=10)
- <a name="q3-b"></a>**b 画像の掲載と補正**（正答 **ウ**）
  表示機器間の色のずれには、色空間を示すICCプロファイルが手がかりになる。画像補正では明るさ・彩度・輪郭を個別に見る。 [原本 p.10](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=10)
- <a name="q3-c"></a>**c 画像合成**（正答 **オ**）
  マスクの白黒で画素をどちらの入力から取るか決める。中間値のマスクなら、両方の入力を重み付きで混ぜられる。 [図表・原本 p.11](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=11)
- <a name="q3-d"></a>**d 鏡映・回転・縮小**（正答 **ウ**）
  y軸鏡映→反時計回り90度→y方向を半分にすると、平行移動前の点は (−y, −x/2)。最後に図が示す位置に移す。 [図表・原本 p.12](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=12)
- <a name="q3-e"></a>**e カットをつなぐ映像編集**（正答 **エ**）
  カットをつなぐ編集法をモンタージュという。同じ顔でも前後のカットによって印象が変わるのがクレショフ効果。 [図表・原本 p.13](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=13)

<a name="q4"></a>

## 第4問

- <a name="q4-a"></a>**a 波形の標本化と量子化**（正答 **ウ**）
  18 Hzなら1/18秒おきに値を読み、3ビットなので振幅を8段階に割り当てる。グラフは時間間隔と量子化後の高さの両方で絞る。 [図表・原本 p.14](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=14)
- <a name="q4-b"></a>**b Unicode**（正答 **ウ**）
  UTF-8ではASCIIの範囲が同じ1バイト値になる。その他の文字には複数バイトを使う。 [原本 p.15](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=15)
- <a name="q4-c"></a>**c 音響エフェクタ**（正答 **ア**）
  帯域ごとの強さを調整するのはイコライザ。小さい信号を持ち上げる処理はこの設問ではエキスパンダ、上限を超えた信号を抑えるのはリミッタ。 [原本 p.15](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=15)
- <a name="q4-d"></a>**d 表色系**（正答 **ウ**）
  マンセル表色系は色相・明度・彩度で色を整理する顕色系。マンセルの色立体では中心軸から離れるほど彩度が高い。 [図表・原本 p.16](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=16)

## 第5問

- <a name="q5-a"></a>**a インタプリタとコンパイラ**（正答 **オ**）
  コンパイラは実行前にコードを変換する。JavaやC#では中間コードを使う。インタプリタはコードを解釈しながら処理を進める。 [原本 p.17](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=17)
- <a name="q5-b"></a>**b プログラミングとデータベースの処理**（正答 **ウ**）
  仕様やアルゴリズムの整理に続いて、プログラミングではコンピュータが実行できる形に処理を書く。 [原本 p.17](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=17)
- <a name="q5-c"></a>**c SQLでのデータ抽出**（正答 **ウ**）
  INNER JOINで利用者IDと会員IDを対応させ、WHEREで2023年1月1日以降に絞り、SELECTの氏名・電話番号・貸出日の3列だけを返す。該当は3件。 [図表・原本 p.18](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=18)
- <a name="q5-d"></a>**d 操作に伴うテーブルの更新**（正答 **オ**）
  新たな貸出では現在の状態と貸出履歴を更新する。会員や拠点のマスタ情報はその取引で変更する必要がない。 [図表・原本 p.19](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=19)

## 第6問

- <a name="q6-a"></a>**a コンピュータのハードウェア**（正答 **ウ**）
  USBは異なる周辺機器を共通に接続するためのインタフェース。CPU・記憶装置・入出力装置はそれぞれの役割を持つ。 [原本 p.20](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=20)
- <a name="q6-b"></a>**b OS上でのアプリ動作**（正答 **イ**）
  OSのAPIを使うと、アプリはハードウェアを直接制御せずに機能を利用できる。共通処理はライブラリでも再利用できる。 [原本 p.20](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=20)
- <a name="q6-c"></a>**c サーバとネットワークの仮想化**（正答 **イ**）
  1台に複数の仮想サーバを載せられる。古いOSをVMとして動かせば、現在のOS上で動かない旧アプリを利用できる場合もある。 [原本 p.21](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=21)
- <a name="q6-d"></a>**d クラウドサービス**（正答 **ウ**）
  アンマネージドではOSやアプリの運用を利用者が担うことが多い。管理を委ねられる範囲はマネージドの契約内容で決まる。 [原本 p.21](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=21)

## 第7問

- <a name="q7-a"></a>**a IPアドレスなどのネットワーク基礎**（正答 **ウ**）
  127.0.0.1はIPv4のループバックで自分自身を指す。ネットワーク通信で接続の端点を指すときはIPアドレスとポートを区別する。 [原本 p.22](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=22)
- <a name="q7-b"></a>**b 伝送速度と容量**（正答 **イ**）
  1,920×1,080×24×100＝4,976,640,000ビット。12,000,000 bit/sで割ると約415秒で、約400秒が近い。 [原本 p.22](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=22)
- <a name="q7-c"></a>**c ネットワーク区間どうしの接続**（正答 **エ**）
  別IPセグメント間をつなぐにはルーティングが必要。レイヤー3スイッチなら異なるネットワーク間を転送できる。 [図表・原本 p.22](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=22)
- <a name="q7-d"></a>**d 無線通信の種類**（正答 **エ**）
  無線LANはWi-Fi、近接用途はNFCなど、移動体の広域接続は携帯回線。通信距離と用途を対応させる。 [原本 p.23](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=23)

## 第8問

- <a name="q8-a"></a>**a データの可視化**（正答 **イ**）
  蓄積したデータをグラフなどにして理解しやすくすることを可視化という。 [原本 p.24](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=24)
- <a name="q8-b"></a>**b クライアント・サーバ構築時の法務とテスト**（正答 **ウ**）
  単体・結合テストに合格しても規模の限界は分からない。想定利用者数や同時処理量で負荷を検証する。 [原本 p.24](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=24)
- <a name="q8-c"></a>**c シナリオ分析**（正答 **ウ**）
  利用者が実際に目標を達成する手順を追って、迷いやすい誘導や余計な操作を見つけるのがシナリオ分析。 [図表・原本 p.24](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=24)
- <a name="q8-d"></a>**d クライアント・サーバアプリの運用**（正答 **カ**）
  クラウドでは必要に応じてサーバ数を増やせる。安定運用には監視・冗長化・保守も必要。 [原本 p.25](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=25)

## 第9問

- <a name="q9-a"></a>**a ネット上のビジネス形態**（正答 **エ**）
  ネットバンキングでは残高照会や振込などを利用できる。不正ログインや取引の防止にワンタイムパスワードなどが使われる。 [原本 p.26](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=26)
- <a name="q9-b"></a>**b Cookie**（正答 **イ**）
  Cookieは識別子などを保持するデータ。ページを動かすJavaScriptの通常の配布場所ではない。 [原本 p.26](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=26)
- <a name="q9-c"></a>**c 情報共有サイト**（正答 **ア**）
  DOIは論文などのデジタル資料を継続的に識別するID。機関リポジトリは資料の保存やアクセスを担う。 [原本 p.27](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=27)
- <a name="q9-d"></a>**d 利用者が参加するメディアとマーケティング**（正答 **ウ**）
  利用者が投稿して成り立つ媒体はCGM。広告や販売への流れと、媒体を作る主体とを分けて考える。 [原本 p.27](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=27)

## 第10問

- <a name="q10-a"></a>**a 映像配信**（正答 **エ**）
  ユニキャストは受信先ごとに通信し、マルチキャストはグループ向けで経路の分岐点で複製できる。 [原本 p.28](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=28)
- <a name="q10-b"></a>**b 音声通話の技術**（正答 **オ**）
  IP電話はVoIPで音声を運ぶ。事業者が電話網と相互接続しているサービスでは一般の固定電話にも発着信できる。 [原本 p.28](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=28)
- <a name="q10-c"></a>**c ネット利用時の脅威**（正答 **オ**）
  SNSの投稿は第三者にも読まれる可能性がある。公開範囲、他人のプライバシー、パスワード管理を確認する。 [原本 p.29](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=29)
- <a name="q10-d"></a>**d SSL/TLSなどのセキュリティ**（正答 **エ**）
  VPNは公衆回線上に利用者を限定した経路を作る。TLSはアプリ間の通信保護などに用いられ、用途は同じとは限らない。 [原本 p.29](https://www.cgarts.or.jp/v1/kentei/past/img/2023_11/t/e/exp_mm_23b.pdf#page=29)
