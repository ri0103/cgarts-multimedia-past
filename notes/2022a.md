## 第1問（共通問題）

- <a name="q1-1"></a>**（1） 著作財産権の内訳**（正答 **ア**）
  公衆送信権はネット配信などに関わる著作財産権。著作者名をどう出すかを決める氏名表示権は人格権に当たる。 [原本 p.4](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=4)
- <a name="q1-2"></a>**（2） 著作権が発生する条件**（正答 **エ**）
  著作権は原則創作時に生じ、レコード製作者の著作隣接権も最初の録音の際に登録なしで生じる。 [原本 p.4](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=4)
- <a name="q1-3"></a>**（3） 著作者の考え方**（正答 **エ**）
  創作に年齢制限はない。小学生でも実質的に表現を創作すれば著作者になれる。 [原本 p.4](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=4)
- <a name="q1-4"></a>**（4） 著作物の該当例**（正答 **イ**）
  自動で録画しただけの監視映像のように創作的な表現のない記録は、著作物性を認めにくい。 [原本 p.4](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=4)

## 第2問

- <a name="q2-a"></a>**a 背景色による色の見え方**（正答 **ウ**）
  同じオレンジでも背景との色相差が強調されると違う色味に見える。これが色相対比。 [図表・原本 p.8](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=8)
- <a name="q2-b"></a>**b 画素数と解像度から求める印刷寸法**（正答 **ア**）
  各辺を1,200 dpiで割りインチに直し、25.4 mmを掛ける。2,592×1,944画素なら約55×41 mm。 [原本 p.8](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=8)
- <a name="q2-c"></a>**c 色の見え方に関する現象**（正答 **イ**）
  鮮やかさの差が強まるのは彩度対比、物理量と見え方がずれるのは錯視、まとまって見えるのは群化、周囲の色に寄るのは同化。 [原本 p.9](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=9)
- <a name="q2-d"></a>**d 隠れた線や面の除去**（正答 **ア**）
  手前に隠れる線や面を省くと、複数の立体の前後関係が見えやすい。 [図表・原本 p.9](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=9)
- <a name="q2-e"></a>**e ぼけた輪郭の画像処理**（正答 **ウ**）
  ぼけた輪郭をくっきりさせるには鮮鋭化で明暗の変化を強める。平滑化は細かい変化を抑えるため効果が逆になる。 [図表・原本 p.10](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=10)

## 第3問

- <a name="q3-a"></a>**a 可視光と波長**（正答 **ウ**）
  目に見える光を可視光という。赤外線は可視光の赤側より長く、紫外線は紫側より短い。 [原本 p.11](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=11)
- <a name="q3-b"></a>**b 聴覚の効果**（正答 **オ**）
  BGMが他の音を覆うのはマスキング。多くの話し声の中から会話を選び取るのはカクテルパーティ効果。 [原本 p.11](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=11)
- <a name="q3-c"></a>**c 再生と再認**（正答 **ウ**）
  再認は表示された候補が覚えているものかを判断すること。記憶から自力で名前を引き出すのは再生。 [原本 p.12](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=12)
- <a name="q3-d"></a>**d 人とコンピュータの対話**（正答 **ウ**）
  物の形が行為を誘うアフォーダンスと、よく知る物になぞらえるメタファを区別する。 [原本 p.12](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=12)

## 第4問

- <a name="q4-a"></a>**a 情報を表し運ぶメディア**（正答 **イ**）
  文字や音は情報を人が理解できる形にする表現メディア。記録・配布・通信を受け持つのが伝達メディア。 [図表・原本 p.13](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=13)
- <a name="q4-b"></a>**b ASCIIと文字コード**（正答 **ア**）
  ASCIIで大文字Cは16進数43。コード表では上位の桁と下位の桁を組み合わせる。 [図表・原本 p.14](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=14)
- <a name="q4-c"></a>**c 波形符号化と音声の符号化**（正答 **エ**）
  LPCは声の生成モデルを使う分析合成、CELPは分析合成と波形の工夫を併用、PCMは波形の標本値を符号化する。 [図表・原本 p.15](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=15)
- <a name="q4-d"></a>**d カラーマネジメント**（正答 **ア**）
  ICCプロファイルで機器固有の色を共通の色空間に対応づけ、別の機器で近い色を再現する。 [図表・原本 p.16](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=16)

## 第5問

- <a name="q5-a"></a>**a GPU**（正答 **エ**）
  GPUはグラフィックスなどの並列計算に使われる。中央演算装置を意味するのはCPU。 [原本 p.17](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=17)
- <a name="q5-b"></a>**b ソフトウェアライブラリ**（正答 **イ**）
  ライブラリは共通処理を再利用する部品。リンクにはコードを実行ファイルへ組み込む方法と、共有ライブラリを別に参照する方法がある。 [原本 p.17](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=17)
- <a name="q5-c"></a>**c デスクトップ仮想化**（正答 **イ**）
  VDIの作業環境はサーバ側。端末は主に表示と入力を担当し、端末へのデータ保存や外部持ち出しの可否は設定によって決まる。 [図表・原本 p.18](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=18)
- <a name="q5-d"></a>**d クラウドの拠点と地域**（正答 **ウ**）
  クラウドの地理的な拠点単位をリージョンという。リージョン内で障害分離された配置単位をゾーンと呼ぶことがある。 [原本 p.18](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=18)

## 第6問

- <a name="q6-a"></a>**a 条件分岐のフローチャート**（正答 **ウ**）
  2で割った余りが0のときだけ表示して終了する。偽の分岐では表示を飛ばす。 [図表・原本 p.19](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=19)
- <a name="q6-b"></a>**b 関数**（正答 **ア**）
  関数に渡す値は引数、関数から呼び出し元へ返す値は戻り値。 [原本 p.19](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=19)
- <a name="q6-c"></a>**c ソースコードの実行方式**（正答 **イ**）
  ソースコードを解釈しながら動かす方式がインタプリタ方式。コンパイラ方式では実行前に別の形式へ変換する。 [図表・原本 p.20](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=20)
- <a name="q6-d"></a>**d ロックとトランザクション**（正答 **エ**）
  複数の操作を一つのまとまりとして扱うのがトランザクション。ロックは並行処理の競合を制御する。 [原本 p.20](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=20)

## 第7問

- <a name="q7-a"></a>**a TCP/IPの階層とヘッダ**（正答 **エ**）
  データを下の層に渡すたびに必要なヘッダを付けるのがカプセル化。TCPならセグメント、IPならパケットという単位で扱う。 [図表・原本 p.21](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=21)
- <a name="q7-b"></a>**b インターネット上の機器の識別**（正答 **エ**）
  ネットワーク上の機器の識別にはIPアドレスを使う。人が読みやすい名前からIPを得るのはDNSの役割。 [原本 p.21](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=21)
- <a name="q7-c"></a>**c アクセスポイントを使う無線LAN**（正答 **エ**）
  無線端末がアクセスポイントを経由する方式はインフラストラクチャモード。端末どうしが直接通信する方式と区別する。 [図表・原本 p.22](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=22)
- <a name="q7-d"></a>**d ネットワークセキュリティ**（正答 **エ**）
  プロキシはキャッシュによる効率化に加え、接続先の制御などセキュリティ目的にも使われる。IDSは検知、IPSは防止を担う。 [原本 p.22](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=22)

## 第9問

- <a name="q9-a"></a>**a DNS**（正答 **ウ**）
  DNSは階層型で、委任されたドメインの配下は組織が名前を管理できる。 [原本 p.25](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=25)
- <a name="q9-b"></a>**b eラーニング**（正答 **ア**）
  eラーニングは教材を繰り返し提供できる。演習や討論を組み合わせることで視聴だけの受け身にしない工夫ができる。 [原本 p.25](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=25)
- <a name="q9-c"></a>**c クラウドサービスの分類**（正答 **ウ**）
  アプリを開発・動作させる基盤を提供するのがPaaS。利用者が完成アプリを使うSaaS、仮想計算資源を借りるIaaSと区別する。 [原本 p.26](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=26)
- <a name="q9-d"></a>**d 広告取引のしくみ**（正答 **ア**）
  アドエクスチェンジは広告枠の取引市場。広告主側のDSPと媒体側のSSPをつなぐ。 [図表・原本 p.26](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=26)

## 第10問

- <a name="q10-a"></a>**a 生活に使われるICT**（正答 **ウ**）
  機器をネットに接続して活用するのがIoT。金融サービスに情報技術を取り入れるのがフィンテック。 [原本 p.27](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=27)
- <a name="q10-b"></a>**b 高度道路交通システム（ITS）**（正答 **ウ**）
  ETC2.0は通行料金の処理に加えて路側設備との情報交換にも対応。一般的なGPS測位では緯度・経度・高度と時計のずれのため4機以上を使う。 [原本 p.27](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=27)
- <a name="q10-c"></a>**c シンクライアント**（正答 **イ**）
  シンクライアントではデータや処理をサーバ側に置き、端末には主に入力と画面表示を担わせる。 [原本 p.28](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=28)
- <a name="q10-d"></a>**d マルウェアへの対策**（正答 **イ**）
  定義ファイルには既知のマルウェアを識別する情報が入る。更新して新しい検出対象に対応する。 [図表・原本 p.28](https://www.cgarts.or.jp/v1/kentei/past/img/2022_07/t/e/exp_mm_22a.pdf#page=28)
