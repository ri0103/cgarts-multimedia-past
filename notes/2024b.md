## 第1問（共通問題）

- <a name="q1-1"></a>**（1） 著作権の分類と扱い**（正答 **ア**）
  譲渡できる著作財産権と、本人に帰属し続ける著作者人格権を区別する。 [原本 p.4](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=4)
- <a name="q1-2"></a>**（2） 著作物の要件**（正答 **イ**）
  下書きでも創作的な表現があれば著作物になり得る。完成・出版を待つ必要はない。 [原本 p.4](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=4)
- <a name="q1-3"></a>**（3） 作品の類似と著作権侵害**（正答 **ウ**）
  類似だけでなく元作品への依拠があるかを見る。偶然の一致と、元作品の創作的表現を利用した場合は扱いが異なる。 [原本 p.5](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=5)
- <a name="q1-4"></a>**（4） 知的財産法と保護対象**（正答 **イ**）
  実用新案は物品の形状・構造などの考案を対象とする。検索のような方法そのものは実用新案の対象から外れる。 [原本 p.5](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=5)

## 第2問

- <a name="q2-a"></a>**a 色相対比**（正答 **ウ**）
  同じ紫でも背景が違えば色味が変わって見える。色相対比は背景との色相差が大きく見える現象。 [図表・原本 p.8](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=8)
- <a name="q2-b"></a>**b 印刷解像度の単位**（正答 **エ**）
  dpiは1インチ当たりの点の数。印刷寸法×dpiから必要な点の数を求められる。 [原本 p.8](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=8)
- <a name="q2-c"></a>**c 画像補正**（正答 **ア**）
  彩度を下げると色味が弱くなり、鮮鋭化するとエッジが強調される。両者は画像の別の性質を変える。 [図表・原本 p.9](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=9)
- <a name="q2-d"></a>**d 画素による画像表現**（正答 **エ**）
  ラスタは画素の色や明るさを格子状に記録する。ベクタは図形の座標や式を記録する。 [原本 p.10](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=10)
- <a name="q2-e"></a>**e 形状の集合演算**（正答 **イ**）
  AとBを和集合でまとめ、それからCと重なる部分を引く。演算順の指定に従うことが大事。 [図表・原本 p.10](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=10)

<a name="q3"></a>

## 第3問

- <a name="q3-a"></a>**a 両眼で捉える奥行き**（正答 **エ**）
  対象が遠いほど左右の目が内向きに寄る角度（輻輳角）が小さくなり、左右の網膜像の差も小さくなる。 [原本 p.11](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=11)
- <a name="q3-b"></a>**b 聴覚の効果**（正答 **キ**）
  口の動きによって違う音節に聞こえるのがマガーク効果。別音に覆われるマスキングや、声を選び取るカクテルパーティ効果と分ける。 [原本 p.11](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=11)
- <a name="q3-c"></a>**c 記憶の三過程**（正答 **ア**）
  感覚記憶は感覚入力を瞬間的に残す。短期記憶は少量を一時保持し、長期記憶は体験や知識を長く保持する。 [原本 p.12](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=12)
- <a name="q3-d"></a>**d 機器の使いやすさ**（正答 **オ**）
  ユーザー体験には機能と外観に加え、利用中に感じる負担や納得感も含まれる。操作への即時フィードバックは状態を理解する助けになる。 [原本 p.12](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=12)

<a name="q4"></a>

## 第4問

- <a name="q4-a"></a>**a 可聴域と標本化周波数**（正答 **ウ**）
  上限20 kHzの音なら、標本化周波数の目安はその2倍の40 kHz。 [原本 p.13](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=13)
- <a name="q4-b"></a>**b 音声ビットレート**（正答 **エ**）
  毎秒40,000標本×16ビット＝640,000 bit/s、すなわち640 kbit/s。 [原本 p.13](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=13)
- <a name="q4-c"></a>**c 文字コード**（正答 **ア**）
  標準ASCIIは日本語の仮名や漢字を含まない。Unicodeは世界の文字を統一した番号体系で扱う。 [原本 p.13](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=13)
- <a name="q4-d"></a>**d 表色系**（正答 **イ**）
  顕色系の例であるマンセル表色系は色相・明度・彩度。RGBは光の混合量で表す混色系の例。 [原本 p.14](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=14)

## 第5問

- <a name="q5-a"></a>**a ハードウェアの要素**（正答 **ア**）
  USBはデータ転送だけでなく給電にも使える。USB PDは規格に応じて充電・電源供給を行う。 [原本 p.15](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=15)
- <a name="q5-b"></a>**b プロセッサの仕様**（正答 **ウ**）
  CPUは汎用処理と命令の実行を担う。GPUは画像やCGのほか機械学習などの並列計算にも使われる。 [原本 p.15](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=15)
- <a name="q5-c"></a>**c ソフトウェアの分類と役割**（正答 **ウ**）
  OSはプロセスやメモリを管理し、プロセス間通信も提供する。フレームワークはアプリ開発の土台になる再利用可能な部品や構造。 [原本 p.16](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=16)
- <a name="q5-d"></a>**d 仮想化**（正答 **イ**）
  仮想化したサーバは追加・削除しやすく、負荷に応じた拡張や物理資源の集約に使える。 [原本 p.16](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=16)

## 第6問

- <a name="q6-a"></a>**a 通信プロトコルの役割**（正答 **イ**）
  TCPは順序や再送を扱って信頼性を確保する。送信先へパケットを届ける役割はIP。 [原本 p.17](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=17)
- <a name="q6-b"></a>**b IPv4とIPv6**（正答 **ア**）
  IPv4とIPv6はそのまま相互通信する規格ではない。デュアルスタックは両方を実装して使い分ける。 [原本 p.17](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=17)
- <a name="q6-c"></a>**c ドメイン名とDNS**（正答 **ウ**）
  DNSは名前を解決する。一般のクライアントすべてに公開ドメイン名が必要なわけではない。 [原本 p.18](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=18)
- <a name="q6-d"></a>**d モバイル回線**（正答 **ア**）
  携帯端末は近くの基地局を通じて事業者のコアネットワークにつながる。相手が携帯なら相手側の基地局も経由する。 [原本 p.18](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=18)

## 第7問

- <a name="q7-a"></a>**a 公開鍵暗号と応用**（正答 **イ**）
  暗号化は受信者の公開鍵と秘密鍵、署名は署名者の秘密鍵と公開鍵で役割が分かれる。署名の検証を一般的な「秘密鍵による暗号化の復号」と同一視しない。 [原本 p.19](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=19)
- <a name="q7-b"></a>**b ファイアウォールとフィルタリング**（正答 **ウ**）
  パケットフィルタはIPアドレスやポートなどで判定する。URLやコンテンツベースの制御とは判定対象が異なる。 [原本 p.19](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=19)
- <a name="q7-c"></a>**c 多要素認証の組み合わせ**（正答 **ア**）
  パスワード、暗証番号、生年月日はすべて知識要素。異なる種類の要素がなければ多要素にならない。 [原本 p.20](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=20)
- <a name="q7-d"></a>**d セキュリティと事業継続**（正答 **イ**）
  BCPは障害や災害を想定して重要業務を復旧・継続する計画。遠隔接続の暗号化は通信を守る別の対策。 [原本 p.20](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=20)

## 第8問

- <a name="q8-a"></a>**a WebアプリとAPI**（正答 **エ**）
  要求を受けてサーバ側で結果を作る場合は動的コンテンツ。Web APIは別のプログラムからWeb経由で機能を使うための窓口。 [原本 p.21](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=21)
- <a name="q8-b"></a>**b アプリ開発と要件定義**（正答 **エ**）
  単体テストで見つかった問題は、原因を調べ修正と再確認を行う。結合テストは部品同士の連携を確認する。 [原本 p.21](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=21)
- <a name="q8-c"></a>**c 新しいアプリ開発手法**（正答 **オ**）
  ノーコードはコードを書かずに既成部品を組む。ローコードは必要な部分にコードを足す。いずれも適用できる範囲はツールに左右される。 [原本 p.22](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=22)
- <a name="q8-d"></a>**d マルチクラウド**（正答 **ウ**）
  複数クラウドを使うと選択肢が増える反面、接続・アクセス制御・運用の管理が複雑になる。 [原本 p.22](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=22)

## 第9問

- <a name="q9-a"></a>**a Webブラウザ**（正答 **イ**）
  HTMLとCSSを使っても、実装やフォント、画面幅などの違いで全ブラウザの表示が同一になるとは限らない。 [原本 p.23](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=23)
- <a name="q9-b"></a>**b Webメール**（正答 **ア**）
  Webメールはブラウザから利用でき、端末にメール専用アプリを入れずに使える。ブラウザとWebメールサービスはHTTP(S)でやり取りする。 [原本 p.23](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=23)
- <a name="q9-c"></a>**c ホスティングとハウジング**（正答 **ウ**）
  ホスティングはサーバを提供・貸し出す形。ハウジングは持ち込みサーバの設置場所を提供する形。どちらも施設側の電源・回線を利用できる。 [原本 p.24](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=24)
- <a name="q9-d"></a>**d ネット事業とマーケティング**（正答 **イ**）
  BTOは受注後に組み立てる方式。ネットで集客する施策は検索・外部リンクと自社サイトへの導線を結びつけて考える。 [原本 p.24](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=24)

## 第10問

- <a name="q10-a"></a>**a エッジコンピューティング**（正答 **ア**）
  エッジ処理はデータ発生源に近い場所で計算するので、通信の往復を減らして低遅延にしやすい。 [原本 p.25](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=25)
- <a name="q10-b"></a>**b 生成AIと基盤モデル**（正答 **カ**）
  生成AIは指示から文や画像を生成し、画像のスタイル変換にも使える。生成した内容の事実性は別途確認する。 [原本 p.25](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=25)
- <a name="q10-c"></a>**c 他者の文章の流用**（正答 **エ**）
  出典を示さず他人の表現を自作として扱う行為は剽窃。引用の方法と著作権侵害の判断は分けて考える。 [原本 p.26](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=26)
- <a name="q10-d"></a>**d 情報漏えい防止**（正答 **ウ**）
  公衆Wi-Fiで平文HTTPを使うと通信を保護できない。バックアップも保管先とアクセス制御が適切でなければ情報漏えいの経路になり得る。 [原本 p.26](https://www.cgarts.or.jp/v1/kentei/past/img/2024_11/t/e/exp_mm_24b.pdf#page=26)
