## 本番形式で解く

1. 1検定受験の試験時間は80分です。第1問の共通問題と第2〜10問を解きます。
2. マークシートを使う場合、第1問は表面の共通欄、第2〜10問は裏面のマルチメディア検定欄に記入します。 [2026年前期のマークシート](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2026/a/2026a_sheet_ex.pdf) · [2025年後期のマークシート](https://www.cgarts.or.jp/static/past_download/past_download_files/pdf/2025/b/2025b_sheet_ex.pdf)
3. 配点付きの2026年前期は100点満点で自己採点できます。公式の合格基準点は70点です。 [受験要項](https://www.cgarts.or.jp/kentei/guidance/)
